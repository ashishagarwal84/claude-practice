# claude-practice — Sandbox Project

## What This Project Is
This is a practice/sandbox repository for learning to use Claude Code.
Use it to try commands, experiment with features, and practice the workflow.
Nothing here is critical -- feel free to break things and redo them.

## Stack
- Plain HTML, CSS, and JavaScript (no frameworks -- keep it simple)
- No database
- No build tools required

## Rules for This Project
- Keep all code simple and readable (I am learning)
- Always explain what you are doing in plain English
- One small change at a time
- Test in the browser after each change

## How to Run
- Open index.html in any browser (just double-click the file)
- No server needed for basic HTML/CSS/JS

## Practice Goals
- [ ] Build a simple todo list app
- [ ] Add a dark mode toggle
- [ ] Save todos to browser localStorage
- [ ] Add a simple search/filter

## Commands
| Task        | How                        |
|:------------|:---------------------------|
| Save work   | /save                      |
| Review code | /review                    |
| New feature | /new-feature "description" |
| Start fresh | /prime                     |
