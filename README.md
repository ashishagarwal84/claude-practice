# Claude Practice Sandbox

A sandbox project for learning Claude Code workflows.

## What's Inside
This repo is for practicing:
- Using Claude Code slash commands (/plan, /review, /save, /prime)
- Making git commits
- Building simple HTML/CSS/JS projects

## How to Use
1. Open a terminal in this folder
2. Run: `claude`
3. Try: `/prime` then describe what you want to build
